# BERT GPU vs CPU — 2026-11-02

## Методика

Один и тот же CPU/GPU token-classifier EuroBERT-210m:

- CPU: `ioc_classifier_service.py`, `172.17.0.1:8002`, 4 воркера;
- GPU: `ioc_classifier_gpu.py`, `172.17.0.1:8003`, CUDA, FP16;
- 22 уникальных исходных письма;
- полный текст без обрезки на 20k;
- один проход после warmup;
- для самого длинного письма 9/99 — 3 дополнительных замера.

## Вывод

- GPU-BERT примерно в **10–11 раз быстрее** CPU-BERT.
- GPU использует около **0.5 GB** дополнительной VRAM.
- Но GPU общий с vLLM: vLLM уже занимает ~11.6 GB из 16 GB, поэтому BERT на GPU увеличивает конкуренцию за VRAM/вычисления.
- CPU-вариант оставлен в работе по ранее заданному режиму; GPU-сервис после теста остановлен.
- Для полного пайплайна выигрыш будет меньше, чем 11x: BERT работает параллельно с LLM и не является единственным критическим путём. При 9/99 CPU-BERT занимает ~4 с из ~23 с общего времени.
