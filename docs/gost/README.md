## Пересборка

```powershell
python docs/gost/build_gost_docs2.py
& "C:\\Program Files\\LibreOffice\\program\\python.exe" docs/gost/finalize_gost_docs.py
```

Скрипт читает исходные копии из `docs/Комплект_документации/_backup_20261116`, собирает новые DOCX и сохраняет их в `docs/Комплект_документации`.

Параметры оформления: A4, поля 30/15/20/20 мм, Times New Roman 14, интервал 1,5, абзац 1,25 см, выравнивание по ширине, титульный лист, аннотация, содержание, перечень сокращений, список источников и лист регистрации изменений. Номера страниц — в нижнем колонтитуле; титульный лист без номера. Лист утверждения и подписи в комплект не включаются.

После сборки DOCX выполняется `finalize_gost_docs.py` — он обновляет содержание и номера страниц через LibreOffice и формирует PDF в `docs/Комплект_документации`.

## Ограничения

- Содержание и структура документов приведены к ГОСТ 19.106-78 / 19.105-78, 34.201-2020 и 59795-2021; для 06–07 использованы подходы ГОСТ 7.32-2017 и 59792-2021.
- Содержание и номера страниц актуализируются финализатором; для пересборки нужен LibreOffice.
- PDF-версии формируются `finalize_gost_docs.py`.
- Старый отчёт `06_...pre_security_20261116.docx` перенесён в `_backup_20261116/_history` и в передаваемый комплект не входит.
