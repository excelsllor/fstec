# Примеры оформления

Материалы скачаны для изучения структуры и визуального оформления; в комплект документации их текст не переносился.

- `tdocs-rukovodstvo.html` — пример руководства оператора по ГОСТ 19.505-79.
- `student-it-260018.pdf` — учебный материал с примерами программной документации (титул, аннотация, содержание).
- `student-it-225705.html` — пример практической разработки руководства оператора.
- `student-it-267353.html` — пример пояснительной записки к техническому проекту.
- `appliner-tz.html` — пример структуры технического задания по ГОСТ 34.602-2020.
- `authorit-24851.html` — пример аннотации и структуры руководства оператора.
- `znanio-operator.html` — пример руководства оператора для учебной информационной системы.

При использовании примеров проверялись: титульный лист, аннотация, содержание, нумерация разделов, подписи таблиц, список источников и приложения.
