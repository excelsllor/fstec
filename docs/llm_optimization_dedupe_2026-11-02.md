# LLM optimization #1 — prompt dedupe

## Изменение

Включён `FSTEC_DEDUPE_PROMPT_LINES=1` для LLM-сервиса. Перед вызовом vLLM из prompt удаляются точные повторы длинных строк (колонтитулы, повторяющиеся шапки).

Изменение только runtime-конфигурацией; исходный код и формат ответа не менялись.

## Проверка

- 22 уникальных письма.
- До: 22/22 завершены, общий прогон `09:55:49–10:04:20` ≈ **8 мин 31 с**.
- После: 22/22 завершены, общий прогон `10:11:40–10:20:29` ≈ **8 мин 49 с**.
- GPU во время LLM-этапа остаётся загруженным; выигрыша по времени нет.
- Полевые метрики не изменились:
  - CVSS 99.55%
  - severity 97.29%
  - применимость 99.49%
  - меры F1 98.21%

## Вывод

**Оптимизация не дала эффекта и откачена** (`FSTEC_DEDUPE_PROMPT_LINES=0`).

Причина: в реальных письмах нет достаточного количества точных повторяющихся длинных строк; основное время LLM тратится на inference/токены, а не на дублирование prompt.
