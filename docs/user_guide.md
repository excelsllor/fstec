# Руководство пользователя

## Вход

Откройте веб-интерфейс, введите логин/пароль. При первом запуске используется
bootstrap-учётка администратора с одноразовым паролем.

## Загрузка письма

1. «Загрузить письмо» → перетащите PDF/DOCX/DOC/ODT/XLSX/RTF/TXT или выберите файлы.
2. Можно до 10 файлов, каждый до 20 МБ.
3. После загрузки откроется карточка письма; статус обновляется автоматически.

## Карточка письма

- **Информация** — номер, дата, тип, SLA/маршрутизация, вложения.
- **Угрозы** — группировки, темы, архивы/файлы, меры; меры можно править.
- **IOC** — IP/домены/хэши/e-mail с копированием.
- **Уязвимости** — BDU/CVE, CVSS, ПО, версии, применимость; можно отметить действие.
- **Ответ** — сгенерировать/отредактировать/скачать DOCX.
- **Экспорт** — списки e-mail, IP, доменов и общий IOC (TXT/DOCX).
- **Текст** — исходный текст с подсветкой IP/доменов/CVE.

## Генерация ответа

Нажмите «Сгенерировать». Ответ можно отредактировать в поле и сохранить.
Скачивание — кнопкой DOCX. После изменения мер/уязвимостей ответ нужно сгенерировать заново.

## Ограничения

- Ручная правка IOC/сущностей и версий пока недоступна.
- Карточка индикаторов не перегенерируется после правок; скачивается последняя версия.
- При ошибке 403/500 сообщение может быть общим; повторите действие или обратитесь к администратору.
