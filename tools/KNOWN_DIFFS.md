# Известные различия генерации (allow-list)

Ниже — различия между сгенерированными и реальными ответами, которые **согласованы
как допустимые** и не считаются дефектами. Скрипт `audit_quality.py` подавляет
их через `ALLOWED_MISS_QUOTES`.

## Кавычки-наименования, отсутствующие в генерации

Подавляются аудитом через `ALLOWED_MISS_QUOTES`.

| Письмо | Реальный текст | Причина |
| --- | --- | --- |
| 9-78 | «Направляем Вам Исх № ... от ...» | В реале 3 точки-заглушки, в генерации одна (косметика) |
| 9-81 | «Исх № .. от ..» | В реале 2 точки-заглушки, в генерации одна (косметика) |
| 9-89 | «ishod_6726_dolzhnost.zip» | В источнике «ФНС России.zip»; генерация следует источнику |
| 9-99 | «:FWD :RE Добрый день. Добавил сведения преамбулу и скорректировал п. 4.6. Больше изменений не вносил» | В источнике это цитата из тела переписки; генерация следует источнику. |

## Точки-заглушки и дефекты исходников (не чинить)

- 9-78#1 / 9-81#5: в реальном ответе «Исх № … от …» стоят 2–3 точки-заглушки,
  в генерации одна. Косметика, генерация корректнее.
- 9-89#5: реальный архив назван «ishod_6726_dolzhnost.zip», в источнике
  «ФНС России.zip». Генерация следует источнику.
- 9-99#4: в реальном ответе «с тематикой в «:FWD :RE …»» (лишнее «в» перед
  двоеточием). Генерация следует источнику.

## Что проверяется аудитом

- Смысловое покрытие: каждый реальный абзац должен быть покрыт близким
  сгенерированным (exact >= 0.72 или слово-ratio >= 0.78).
- Сущности: BDU, CVE, email, кавычки-наименования, IP.
- Орфография/пунктуация: двойные пробелы, пробел перед знаком препинания,
  двойные знаки препинания, ведущие/замыкающие пробелы.

## Команды

```bat
python tools\gen_all.py         :: перегенерация 12 ответов в generated_otvety\
python tools\audit_quality.py   :: аудит 12 писем, отчёт в tools\quality_audit.txt
```
